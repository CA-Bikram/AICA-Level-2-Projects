# GujRERA Order 112-A: site board / banner rules

**Order:** GujRERA/Order-112-A, dated 20.12.2025 (Authority approval 19.12.2025). It supersedes Order 112 (28.11.2025) and builds on Order 108 (19.05.2025). It is issued under RERA Act 2016 s.11 and s.37, read with Gujarat RERA (General) Regulations 2017, Reg. 5. It applies to all ongoing registered projects with immediate effect.

## Physical requirements (cl. 4.3)

| Clause | Requirement |
|---|---|
| 4.3.1 | Minimum width 1.20 m, minimum height 2.00 m |
| 4.3.2 | Near the main entrance or visible from the main road, 1.50 m to 2.00 m above ground |
| 4.3.3 | Waterproof material; white or yellow background |
| 4.3.4 | Minimum letter height 2.50 cm; text colours as in the annexed sample |
| 4.3.5 | RERA registration no. and RERA collection bank account details in red |
| 4.3.6 | QR code minimum 15 × 15 cm, easily scannable by mobile |

## Other clauses

- **cl. 5:** Upload a geotagged photo of the board, showing latitude and longitude, with every QPR.
- **cl. 6:** Promoters who don't comply are liable to a penalty.
- **cl. 8:** The Authority's interpretation is final.
- **cl. 9:** A board is not required where the project's QE is uploaded and verified on the GujRERA website.

## Annexure content (labels in black, details in red)

The header reads "…હુકમ નં.૧૧૨-A, તા.૧૯.૧૨.૨૦૨૫ ને આધિન". The board then shows:

- project name
- RERA reg. no.
- promoter name
- authorised e-mail
- authorised mobile
- authorised signatory
- completion date (DD-MM-YYYY)
- construction use (Residential / Commercial / Mix)
- units by block (block no., shops, offices, residences)
- specifications
- amenities
- RERA collection account name
- account no. (only the last 4 digits shown)
- project loan bank / FI

A right-side panel carries the GujRERA website (https://gujrera.gujarat.gov.in) and the project QR code.

The "એલોટીઓને જાહેર સુચના" section has 5 points:

1. Pay booking money only by cheque in the collection account's name, written in English CAPITALS in red.
2. (Printed in red.) Register an AFS in the RERA model format before paying more than 10% of the unit price.
3. Details can be verified via the QR code or the website.
4. Project progress can be checked via the QR code or the website.
5. Complaints can be filed on the GujRERA website with the prescribed fee.
