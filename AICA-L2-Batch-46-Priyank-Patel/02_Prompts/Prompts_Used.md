## Prompt 1: understand the regulation and build the generator

**Input:** the scanned GujRERA Order No. 112-A (3 pages, Gujarati) attached as a PDF

> Please keep this in your memory for this project only and provide a solution to auto-generate the banner.

**AI output**
- Read the scanned Gujarati order page by page and extracted clauses 4.3.1–4.3.6, 5, 6, 8 and 9, plus the Annexure format (all labels, colours and the 5-point notice to allottees).
- Built `GujRERA_Banner_Generator.html`: form, Annexure layout, compliance checks and PDF export at actual size.
- Measured the printed glyph heights of the embedded font, and set the font size so the smallest letter is at least 2.5 cm.
- Found that at the 1.20 m minimum width the board grows to about 5 m tall, so it added board-size presets and a "Find smallest width" option.

**CA review:** confirmed the strict reading of the letter-height rule and checked the layout against the Annexure.

## Prompt 2: fetch the project details from GujRERA

> Please update it so that when the RERA registration number is added, it fetches all the details from the RERA site.

**AI output**
- Studied the GujRERA public website to find the public data sources behind its project search and project pages. They need no login and allow access from a local file.
- Added the lookup: registration number → project ID → registration record, collection account, project details, Form 3 (units per block and loan) → auto-fill.
- Decoded the QR on a real registration certificate. It links to the project's public page, so the tool now generates the same link for the banner QR.
- Tested with a real registered project, then fixed a bug where a second project kept the first project's bank account.

**CA review:** decided which fields to rely on; specifications and amenities stay manual because GujRERA does not publish them.

## Reusable prompt template (for any new regulation)

> I am attaching [regulation / order]. Extract every requirement that affects [the document or output], with clause numbers. Then build a single offline HTML tool that (1) takes [the key identifier], (2) fetches the required data from [public source] if available, (3) produces [the output] exactly in the prescribed format, (4) checks each rule live and shows the clause reference, and (5) exports [PDF / Excel] ready to use. List anything you could not automate, and test the output before handing it over.
