# K D Saree Emporium – Online Saree Showcase

**Author:** Saurabh Jain
**Live project:** https://kdsareeemporium.com/

## About the project
A responsive showcase website for **K D Saree Emporium**, a family-run manufacturer of exclusive fancy embroidered sarees operating from Kolkata and Surat for three generations. The site lets retailers, wholesalers and end customers browse the latest designs straight from the factory and enquire directly.

## Problem it solves
Earlier, new designs were shared one by one as photos over WhatsApp. Buyers had no single place to see the current range, fabrics and rates. This website turns the office's latest design photos into an organised online catalogue.

## Key features
- **Collections catalogue** grouped by fabric – Burburry, Fendy Satin, Fendy Chiffon, Organza, Moss, Sitara, Brasso and more
- **Design cards** showing design number, fabric and rate for each saree
- **Embroidery** section for custom embroidery through the sister unit, Surbhi Embroideries
- **Wholesale** section for retailers and bulk buyers, with pan-India dispatch
- **About** page with the brand's story and heritage
- **Contact / enquiry** via WhatsApp and web enquiry forms
- Mobile-first, fast-loading design

## How it was built
- Built with **Lovable** (AI app builder) – React + TypeScript + Tailwind CSS
- Product photos sourced from the company's Google Drive design folders and served through a CDN (Cloudflare R2)
- Hosted on a custom domain: kdsareeemporium.com

## How to view
Open https://kdsareeemporium.com/ in any browser (desktop or mobile).
